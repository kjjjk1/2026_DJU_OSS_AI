# DataClinic 로컬 시연

`index.html`을 열면 두 공개자료와 가상 의료 기록을 오프라인에서 비교할 수 있습니다. `index.html`, `nhis-codes.js`, `integration.js`, `experiments.js`, `models.js`는 같은 폴더에 두세요.

## Gemini로 설명 받기

1. Python 3.9 이상이 설치된 Windows에서 `start.cmd`를 더블클릭합니다. 추가 패키지는 필요하지 않습니다.
2. 창에 Gemini API 키를 입력하고 Enter를 누릅니다. 입력값은 화면에 표시되지 않으며 이번 실행 동안만 사용합니다. 키 없이 Enter를 누르면 계산 기반 설명으로 실행됩니다. 이미 `GEMINI_API_KEY` 또는 `GOOGLE_API_KEY` 환경변수를 설정했다면 자동으로 읽습니다.
3. 자동으로 열린 브라우저에서 탭과 데이터를 선택합니다. ‘결과 설명’에서 전송할 집계값을 확인하고 버튼을 누릅니다. 로컬 서버 창을 닫으면 연결이 종료됩니다.

기본 모델은 `gemini-3.5-flash-lite`입니다. 다른 구조화 출력 지원 모델을 사용하려면 실행 전에 `GEMINI_MODEL` 환경변수를 지정하세요. 키 권한·모델·호출 한도·네트워크 문제는 화면에 표시됩니다. [Google API 키 안내](https://ai.google.dev/gemini-api/docs/api-key)

## 시연 순서

- **CSV 정제 실험실**에서 허리둘레 결측치 12건에 행 삭제를 적용하면 250행 중 238행이 남습니다. 평균·중앙값 대체의 표준편차와 비교한 뒤 승인한 결과를 내려받습니다. 미국 CDC NHANES 2017–2018 신체계측과 인구통계를 SEQN으로 병합한 뒤 성인 250행을 추출했습니다. 가중치를 적용하지 않은 발췌 자료입니다. [신체계측](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/BMX_J.htm) · [인구통계](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/DEMO_J.htm)
- **국내 검진코드 병합**에서 가상 검진 기록 6행을 공식 코드표와 대조합니다. 같은 허리둘레 명칭을 가진 두 코드, 미등록 코드, 빈 코드가 포함되어 있습니다. ‘검진 CSV 열기’에서 자신의 파일을 선택하고 코드 열을 지정할 수도 있습니다. 병합 파일에는 원래 행과 열, 공단 명칭, 도메인, 검토 상태가 담깁니다. 코드표는 국민건강보험공단 건강검진검사항목기본 2024년 7월 31일 기준 1,953행 전체입니다. [공공데이터포털 원본](https://www.data.go.kr/data/15133104/fileData.do)
- **의료 기록 사례**에서 가상 사망 기록을 한 행 추가하면 날짜 충돌 근거와 영향을 받은 문장이 표시됩니다.

CSV 계산과 병합은 브라우저에서 수행합니다. 설명 요청에는 화면에서 미리 볼 수 있는 집계 지표만 사용하며 키는 로컬 Python 서버에서 관리합니다.


## 내 데이터로 분석 결정 비교하기

CSV를 열면 열 역할과 결측 표기를 확인합니다. 식별자와 날짜를 측정값에서 분리하고, 반이나 노선처럼 숫자로 표현된 집단은 집단 역할을 선택하세요. 쉼표로 구분한 결측 표기는 해당 열에만 적용됩니다. 설정은 원본 CSV를 보존합니다.

- **결측치 예측 실습**에서 선택한 열의 대체값을 확인합니다. 내려받는 정제 CSV에는 원본값과 대체값을 구분하는 출처 열이 붙습니다.
- **집단 순위 비교**에서 같은 측정값에 대해 결측 제외 기준과 평균·중앙값·0 대체 기준의 평균과 순위를 대조합니다. 교육 예시는 가상 학생 12명의 자료입니다. 같은 화면에서 다른 CSV의 집단 열과 측정값을 선택할 수 있습니다.
- **예측 변수 비교**에서 목표 측정값과 두 입력 조합을 고릅니다. 같은 행을 대상으로 5겹 교차검증한 릿지 회귀의 평균 절대오차를 기준 모델과 함께 표시합니다. 전처리는 매번 학습 행에서만 수행하며, 결과는 현재 표본의 예측력 비교입니다.
