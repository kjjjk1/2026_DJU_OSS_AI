## 구현 예정 구성
- Python·pandas: 데이터 진단, 정제, 시뮬레이션
- Gemini API: 목적별 가이드 및 정제 위험 설명
- Streamlit: 업로드, 입력, 비교, 선택 및 다운로드 화면

현재는 문서만 등록되어 있습니다. 실제 모듈 경로, 의존성 버전 및 실행 명령은 구현 후 기록합니다.
