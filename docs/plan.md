# DataClinic 프로젝트 계획서

> 이 문서는 프로젝트 목표와 현재 프로토타입 범위를 정리합니다. 구현 여부와 실행 검증 결과는 [최종 결과보고서](final-report.md)에 따로 기록합니다.

## 1. 프로젝트 개요

- 작품명: DataClinic
- 한 줄 소개: AI가 정제 방법을 설명하고 시스템이 영향을 비교하며 사용자가 최종 전처리를 승인하는 브라우저 기반 도구
- 대상: CSV를 다루지만 전처리 기준을 정하기 어려운 학생·연구 입문자·비전공 분석자
- 현재 구현: 단일 HTML 파일로 실행되는 브라우저 프로토타입

## 2. 문제와 해결 방법

결측치, 중복, 이상값 후보를 자동으로 처리하거나 개인별로 수작업하면 정상 데이터를 잘못 제거하고 통계가 왜곡될 수 있습니다. DataClinic은 원본을 보존하고 후보·근거·영향을 보여준 뒤 사람의 결정을 기록하는 흐름을 제공합니다.

## 3. 기능 범위

### 프로토타입에 포함된 기능

- CSV 업로드, 샘플 데이터, 데이터 미리보기
- 정확성·완전성·일관성·유일성·유효성·적시성 관점의 진단 후보
- 문제 값과 원본 행의 연결 및 참조 CSV의 공통 키 기반 조회
- 가능한 전처리 방법의 What-if 비교
- 행 수·결측·기초 통계·분포 등 처리 전후 영향 확인
- 사용자 승인, 이유 입력, 승인 취소, 버전 복원
- 결과 CSV, 이력 JSON, 재실행 Node.js 코드 내보내기
- 선택형 기기 내 AI 또는 OpenAI 호환 Chat Completions API 설명

### 다음 단계에서 검토할 기능

- XLSX 읽기와 내보내기
- 보안이 적용된 서버 측 AI API 프록시
- 여러 사용자가 함께 쓰는 협업·권한 관리 기능
- 실제 데이터셋에서의 진단 정확도 및 사용성 검증
- 발표 PDF와 공개 시연 영상·서비스 주소 등록

## 4. 기술 구성

| 구성 | 역할 |
| --- | --- |
| HTML·CSS·JavaScript | 화면 및 브라우저 내 CSV 진단·전처리 시뮬레이션 |
| 브라우저 File API | 업로드한 CSV 읽기 |
| 기기 내 AI (지원 브라우저) | 선택형 진단 설명 |
| OpenAI 호환 Chat Completions API (선택) | 요약 통계 기반의 한국어 안내 |
| Node.js (선택) | 내려받은 재실행 레시피 실행 |

현재 프로토타입은 서버에 CSV를 업로드하지 않습니다. API 연결 시에는 원본 행 대신 열 이름, 진단 결과와 집계 통계를 요청에 포함합니다. 브라우저에서 API 키를 직접 쓰는 방식은 공개 배포에 적합하지 않으므로 서버 프록시를 별도 구현해야 합니다.
