# DataClinic 프로토타입 시연

## 시연 자료

- 시연 영상: 등록 예정
- 공개 서비스 주소: 아직 없음
- 실행 파일: [DataClinic.html](../src/DataClinic.html)
- 실행 안내: [src README](../src/README.md)

## 실행 환경

- Windows, macOS 또는 Linux의 최신 브라우저
- Python 3가 있으면 별도 설치 없이 정적 웹 서버로 실행 가능
- API 설정 없이 기본 진단과 샘플 시연 가능
- AI API를 연결하려면 유효한 OpenAI 호환 Chat Completions 주소·모델·키가 필요합니다.

프로젝트 루트에서 실행:

~~~~powershell
cd src
py -m http.server 8000
~~~~

브라우저에서 http://localhost:8000/DataClinic.html 을 엽니다.

## 3분 시연 흐름

| 순서 | 화면과 동작 | 설명할 내용 |
| --- | --- | --- |
| 1 | 시작 화면에서 **천식 시연 시작** 선택 | 합성 진료 데이터로 시작합니다. 원본을 브라우저에서 읽고 원본 파일 자체는 덮어쓰지 않습니다. |
| 2 | 문제 목록에서 반복 방문 또는 중복 후보 열기 | 환자 ID와 방문 ID, 문제로 표시된 값, 원본 행의 전체 열을 함께 확인합니다. |
| 3 | 추천 처리 방법과 다른 선택지를 비교 | 예시 데이터에서 환자별 첫 행만 남기는 방식이 중증 기록에 미치는 영향과 방문 단위로 보존하는 방식을 비교합니다. |
| 4 | 영향 비교에서 그래프와 통계 확인 | 처리 전후 행 수·라벨·수치 분포 등 변경 영향을 살펴보고 처리 방법을 결정합니다. |
| 5 | 방법을 승인한 뒤 승인 이력 열기 | 변경 이유와 버전을 확인하고 최근 승인 취소 또는 이전 버전 복원을 보여줍니다. |
| 6 | 결과 내보내기 열기 | 결과 CSV, 승인 이력 JSON, 재실행 코드 기능을 소개합니다. |

AI 안내는 **고급 기능 → AI API 설정**에서 API를 설정한 경우에만 시연합니다. API 요청은 브라우저에서 직접 나가므로 공개 시연에 실제 키를 입력하지 말고, 화면 녹화와 발표 자료에 키가 보이지 않는지 확인하세요. 진단 요약 요청은 원본 행 대신 열 이름과 집계 통계를 사용합니다.

## 시연 전에 확인

- [ ] 천식 시연과 기본 진단이 동작하는지 확인
- [ ] 시연할 CSV가 합성 데이터인지 확인
- [ ] API 키나 개인정보를 화면에 노출하지 않음
- [ ] 데모 후 다운로드 파일과 처리 결과를 확인
- [ ] 영상 링크와 공개 권한을 정한 뒤 이 문서와 루트 README에 반영
