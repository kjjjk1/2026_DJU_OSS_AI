# DataClinic 시연 안내

## 공개 시연

Render 배포 주소와 시연 영상은 준비되는 대로 여기에 추가합니다.

## 로컬에서 실행

Node.js 20 이상이 필요합니다. 저장소 루트에서 PowerShell을 열고 실행합니다.

```powershell
cd src
$env:OPENAI_API_KEY = "발급받은_API_키"
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. API 키는 AI 안내를 사용할 때 필요합니다.

## 3분 시연 · 전국 병원·약국 통합 명부

> 전국 의료기관 수를 집계하려는데, 홈페이지가 없는 기관도 포함해야 할까?

1. **병원·약국 CSV 합쳐서 열기**를 누르고, 병원과 약국의 2026년 9월 원본 CSV를 한 개씩 함께 선택합니다. 브라우저가 두 명부를 합치고 각 행에 기관유형을 표시합니다.
2. 목적을 **빅데이터 분석**으로 두고 검토 목록의 **병원홈페이지** 결측 항목을 엽니다. 병원 홈페이지가 원래 항목에 없는 약국은 해당 없음으로 처리됩니다.
3. **빈칸이 있는 행 빼기**와 **빈 값에 표시 남기기**를 번갈아 선택해 비교합니다.

   | 처리안 | 병원 | 약국 | 통합 목록 |
   | --- | ---: | ---: | ---: |
   | 처리 전 | 79,899 | 25,850 | 105,749 |
   | 홈페이지가 없는 병원 행 제외 | 8,831 | 25,850 | 34,681 |
   | 홈페이지가 없는 병원에 표시만 추가 | 79,899 | 25,850 | 105,749 |

4. Render 앱에서 AI를 연동했다면 **AI 안내**를 눌러 두 방법의 차이를 확인합니다. ‘기관 수 집계가 목적이라 홈페이지 결측만으로 병원을 제외하지 않음’이라는 사유를 적고 표시 열 추가를 승인합니다.
5. 승인 이력을 확인하고 통합 결과를 CSV로 내보냅니다. 재실행 코드를 다운로드하면 원본 두 파일에 같은 병합과 승인 규칙을 적용할 수 있습니다.

```powershell
node recipe.cjs 병원.csv 약국.csv 통합결과.csv
```
