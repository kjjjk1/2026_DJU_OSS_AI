# DataClinic 시연 안내

## 공개 시연

Render 배포 주소와 시연 영상은 준비되는 대로 여기에 추가합니다.

## 로컬에서 실행

Node.js 20 이상이 필요합니다. 저장소 루트에서 PowerShell을 열고 실행합니다.

```powershell
cd src
$env:OPENAI_API_KEY = "발급받은_API_키"
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. API 키는 AI 안내를 사용할 때 필요합니다.

## 3분 시연 · 전국 의료기관 수 집계

1. 첫 화면에서 **병원 CSV 열기**를 누르고 병원정보서비스 원본 CSV를 선택합니다. 파일 선택 창에서 직접 선택하면 브라우저에서 읽습니다.
2. 목적을 **빅데이터 분석**으로 두고 검토 목록의 **병원홈페이지** 결측 항목을 엽니다.
3. **빈칸이 있는 행 빼기**와 **빈 값에 표시 남기기**를 번갈아 선택해 What-if 결과를 확인합니다. 2026년 9월 원본에는 79,899행이 있으며, 홈페이지가 비어 있는 71,068행을 제외하면 8,831행이 남습니다. 표시 열을 추가하면 전체 79,899행이 유지됩니다.
4. Render 앱에 AI를 연결했다면 **AI 안내**에서 두 처리 방법의 차이와 주의사항을 확인합니다.
5. ‘기관 수 집계가 목적이라 홈페이지 결측만으로 기관을 제외하지 않음’이라는 근거를 적고 표시 열 추가를 승인합니다. 승인 이력을 확인하고 결과 CSV를 내보냅니다.
