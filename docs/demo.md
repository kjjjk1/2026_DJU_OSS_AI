## 시연 시나리오
| 순서 | 사용자 동작 | 예상 결과 |
| --- | --- | --- |
| 1 | Streamlit 화면에서 CSV 또는 엑셀 업로드 | 데이터 미리보기 및 입력 확인 |
| 2 | 분석 목적 입력 후 품질 진단 | 결측치·중복·이상치 의심 값 표시 |
| 3 | AI 가이드 확인 | 추천 방법, 근거, 주의사항 표시 |
| 4 | 정제 방법 후보 비교 | 데이터 손실률·결측률·통계 변화 표시 |
| 5 | 왜곡 가능성이 있는 정제 선택 | 해당 조건에 대한 사전 경고 표시 |
| 6 | 방법을 최종 선택하고 다운로드 | 선택이 반영된 파일 저장 |

위 내용은 계획된 시나리오이며, 구현 후 실제 동작에 맞게 수정합니다.
