# DataClinic 시연 안내

## 공개 시연

Render 배포 주소와 시연 영상은 준비되는 대로 여기에 추가합니다.

## 로컬에서 실행

Node.js 20 이상이 필요합니다. 저장소 루트에서 PowerShell을 열고 실행합니다.

```powershell
cd src
$env:OPENAI_API_KEY = "발급받은_API_키"
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. API 키는 AI 안내를 사용할 때 필요합니다.

## 시연 순서

1. **천식 시연 시작**을 누르거나 내장 샘플을 선택합니다.
2. 분석 목적을 설정하고 결측값, 중복·충돌 행, 수치형 이상 후보를 확인합니다.
3. 문제 하나를 선택하고 처리 방법에 따라 행 수와 주요 지표가 어떻게 달라지는지 비교합니다.
4. **AI 안내**를 눌러 추천 근거와 적용 전에 확인할 사항을 살펴봅니다.
5. 처리안을 승인한 뒤 이력을 확인합니다. 이전 버전을 복원하거나 현재 결과를 CSV로 내보낼 수 있습니다.

천식 시연은 앱에 내장된 합성 데이터를 사용합니다. [프로젝트 소개](../README.md) · [최종 결과보고서](final-report.md)
