# DataClinic 발표 자료 구성안

> 기획 내용을 반영한 발표 초안입니다. 실제 구현 화면과 검증 결과는 개발 후 추가하세요.

| 슬라이드 | 제목 | 포함할 내용 |
| --- | --- | --- |
| 1 | DataClinic 소개 | AI 기반 데이터 정제 의사결정 지원 서비스, 팀원 소개 |
| 2 | 해결하려는 문제 | 비전공자의 이상치 판단 어려움, 무분별한 정제에 따른 왜곡 가능성 |
| 3 | 핵심 아이디어 | AI가 근거와 위험성을 설명하고 사용자가 결정 |
| 4 | 주요 기능 | 자동 진단, 목적별 가이드, 위험 경고, 시뮬레이션, 선택형 정제·다운로드 |
| 5 | 시스템 구성 | Python·pandas 데이터 처리, Gemini API 설명, Streamlit 화면 |
| 6 | 프로토타입 시연 | CSV·엑셀 업로드 → 진단 → 가이드 → 시뮬레이션 → 선택·다운로드 |
| 7 | 검증 결과 | 개발 후 진단 정확성·경고 사례·정제 전후 지표를 증빙과 함께 제시 |
| 8 | 기대효과와 확장 | 비전공자 역량 및 분석 신뢰성 향상, 목적별 추천·교육 확장 |
| 9 | 역할 분담 및 한계 | 팀원별 기여, 실제 한계와 개선 방향 |

## 발표 준비
- 계획한 기능과 실제 구현한 기능을 구분합니다.
- 실제 테스트 결과와 화면은 개발 후 추가합니다.
- 완성된 PDF는 `docs/exports/presentation.pdf`에 올리고 루트 README 링크를 변경합니다.
- 발표 시간 및 필수 슬라이드 수는 과제 기준 확인 후 조정합니다.
