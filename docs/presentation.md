| 슬라이드 | 제목 / 요점 | 발표 내용 |
| --- | --- | --- |
| 1 | DataClinic | AI가 제안하고 시스템이 검증하며 사람이 결정하는 데이터 전처리 |
| 2 | 문제 정의: 블랙박스 정제 | 근거 없는 자동 삭제, 사후 통계 왜곡, 끊긴 협업 이력이 만드는 위험 |
| 3 | 합의와 검증 | 블랙박스 자동화와 비교해 사전 What-if, 승인 이력, 재현 가능한 규칙을 제시 |
| 4 | 신뢰 가능한 전처리 파이프라인 | 핵심 기능 설명으로 넘어가는 구분 슬라이드 |

| 7 | 다중 CSV 매칭 검증 | INNER·LEFT·RIGHT·OUTER·CONCAT 방식의 매칭 결과와 행 증가 위험을 비교하는 제안 |
| 8 | 협업과 재현 | 역할별 검토, 결정 기록, 보고서와 재실행 코드로 이어지는 흐름 |

| 10 | 기대효과 | 설치 부담 감소, 결정 이력 보존, 파이프라인 재현성 |
| 11 | 마무리 및 Q&A | 데이터 전처리의 모든 순간을 투명하고 안전하게 |

## 구현 범위 구분

현재 저장소에 포함된 [브라우저 프로토타입](../src/DataClinic.html)은 CSV 진단, 원본 행 근거 확인, 전처리 방법별 What-if 비교, 사용자 승인·버전 복원, CSV·JSON·재실행 코드 내보내기를 제공합니다.

발표 자료의 다중 CSV 병합 방식 비교와 여러 사용자가 참여하는 협업 워크플로는 현재 프로토타입에서 구현된 기능으로 소개하지 말고, 설계 또는 확장 방향으로 구분해 주세요.
