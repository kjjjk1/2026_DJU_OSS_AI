# 발표 자료 구성안

> 아래 내용을 바탕으로 PPT 또는 PDF를 제작하세요. 이 문서는 슬라이드 구성용 초안입니다.

| 슬라이드 | 제목 | 포함할 내용 |
| --- | --- | --- |
| 1 | 프로젝트 소개 | 프로젝트명, 팀원, 한 문장 소개 |
| 2 | 문제와 필요성 | 사용자 문제, 기존 방식의 한계 |
| 3 | 목표와 주요 기능 | 개발 목표, 핵심 기능 |
| 4 | 시스템 구성 | 구성도, 사용 기술, 데이터 흐름 |
| 5 | 핵심 구현 | 주요 모듈, 알고리즘, 구현 근거 |
| 6 | 프로토타입 시연 | 실제 화면, 시연 영상 링크 |
| 7 | 검증 결과 | 테스트 조건, 측정 결과, 비교 |
| 8 | 결론 | 성과, 한계, 개선 방향, 역할 분담 |

## 최종 자료 등록
1. 발표 파일을 PDF로 내보냅니다.
2. `docs/exports/`에 업로드합니다.
3. 저장소 README의 발표 자료 링크를 업로드한 파일로 변경합니다.
4. 실제 발표 시간에 맞춰 분량을 조정합니다.
