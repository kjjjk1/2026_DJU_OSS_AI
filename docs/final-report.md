# DataClinic 최종 결과보고서

> 초안입니다. 현재 확인 가능한 구현 범위만 기록했습니다. 실행 검증, 측정 결과, 팀 기여와 자료 링크는 팀에서 확인한 뒤 채워 주세요.

## 1. 프로젝트 개요

- 프로젝트명: DataClinic
- 작품 설명: AI가 제안하고 시스템이 검증하며 사람이 결정하는 데이터 전처리 도구
- 문제와 목표: 근거 없는 자동 삭제·대체 및 수작업 정제에서 발생하는 데이터 왜곡 위험을 줄이고, 검토 근거와 사용자의 결정을 기록
- 현재 상태: 브라우저 기반 HTML·CSS·JavaScript 프로토타입이 저장소에 포함됨
- 팀원 및 기간: 팀에서 확인 후 기입

## 2. 기능 구현 현황

| 기능 | 코드 상태 | 실행 검증 |
| --- | --- | --- |
| CSV 업로드와 데이터 진단 | 구현 코드 포함 | 팀 확인 후 기록 |
| 문제 후보 및 원본 행 근거 표시 | 구현 코드 포함 | 팀 확인 후 기록 |
| 처리 방법별 What-if 비교 | 구현 코드 포함 | 팀 확인 후 기록 |
| 승인 이력, 승인 취소, 버전 복원 | 구현 코드 포함 | 팀 확인 후 기록 |
| CSV·JSON·Node.js 레시피 내보내기 | 구현 코드 포함 | 팀 확인 후 기록 |
| 선택형 AI 설명 | 기기 내 AI 또는 OpenAI 호환 Chat Completions API 경로 포함 | 브라우저/API별 확인 필요 |

코드와 실행 안내는 [src](../src/)에서 확인할 수 있습니다.

## 3. 시스템 구성

- 화면과 처리: 단일 HTML 파일 안의 HTML·CSS·JavaScript
- 파일 처리: 브라우저 File API를 통한 CSV 읽기
- AI: 지원 브라우저의 기기 내 AI 또는 사용자가 설정하는 OpenAI 호환 Chat Completions API
- 처리 흐름: CSV 읽기 → 진단 후보 표시 → 방법별 영향 비교 → 사용자 승인 → 버전 기록 → 결과 내보내기

AI API를 연결하면 원본 행이 아니라 열 이름, 진단 결과, 집계 통계가 전달됩니다. 현재는 브라우저에서 API를 직접 요청하는 구조이므로 공개 배포에는 서버 프록시가 필요합니다.

## 4. 주요 처리 내용

- 여섯 품질 관점의 진단 후보를 제공하고 후보를 실제 오류로 단정하지 않습니다.
- 원본 데이터는 유지하고 승인한 규칙을 새 버전에 적용합니다.
- 사용자가 처리 전후 행 수·결측·통계·분포 변화를 비교할 수 있게 합니다.
- 결과 CSV, 결정 이력 JSON, Node.js 재실행 코드를 내보낼 수 있습니다.

## 5. 실행 및 재현 방법

[실행 안내](../src/README.md)를 참고하세요.

- 환경: 최신 브라우저, 로컬 정적 웹 서버
- 패키지 설치: 필요 없음
- 명령어: src 폴더에서 py -m http.server 8000 실행
- 접속 주소: http://localhost:8000/DataClinic.html
- 시연 입력: 앱에 포함된 합성 천식·거래 CSV

재현 확인 결과와 사용한 브라우저 버전을 팀에서 기록해 주세요.

## 7. 계획 대비 변경 사항

초기 저장소 계획에는 Python·pandas·Streamlit·Gemini API가 기재되어 있었으나, 현재 등록된 실행 프로토타입은 단일 HTML·CSS·JavaScript 앱이며 선택형 AI 연결은 OpenAI 호환 Chat Completions 인터페이스를 사용합니다. 최종 제출 전 구현 범위와 계획 문서를 함께 확인해 주세요.

## 8. 한계와 다음 작업

- XLSX 입력은 현재 프로토타입 범위에 포함되지 않습니다.
- API 키를 브라우저에서 직접 다루는 방식은 공개 배포에 적합하지 않습니다.
- 여러 사용자가 공동으로 편집하는 온라인 워크스페이스는 제공하지 않습니다.
- 실제 데이터셋 기반 정확도와 사용자 테스트 결과는 아직 이 문서에 기록되지 않았습니다.
- 발표 PDF와 공개 시연 링크를 저장소에 추가해야 합니다.
