AI 기반 데이터 정제 의사결정 지원 서비스

CSV에서 결측값, 중복 행, 이상 후보를 찾고 처리 방법에 따라 결과가 어떻게 달라지는지 미리 비교하세요. AI가 추천 근거와 주의사항을 설명하면, 사용자가 원자료를 확인하고 적용할 방법을 결정할 수 있습니다.

시연 안내 GitHub 저장소

공개 시연 주소는 Render 배포 후 추가됩니다.

주요 기능

CSV 품질 진단

파일을 불러오거나 내장 샘플을 선택해 결측값, 중복·충돌 행, 수치형 이상 후보를 확인합니다.

처리 방법 비교

행 수, 결측값 수, 주요 통계가 어떻게 변하는지 살펴보고 AI 안내에서 선택의 근거를 확인합니다.

승인과 내보내기

선택한 처리 방법을 승인하고, 이력을 확인하거나 이전 버전으로 복원한 뒤 결과를 CSV로 저장합니다.
