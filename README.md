# DataClinic

**AI가 제안하고, 시스템이 검증하며, 사람이 결정하는 데이터 전처리**

DataClinic은 근거 없는 자동 삭제·대체와 개인별 수작업으로 생기는 데이터 왜곡 및 협업 이력 단절 문제를 줄이는 데이터 전처리 의사결정 지원 도구입니다. CSV 품질 진단과 테이블 간 교차 확인, 분석 목적별 정제 추천과 What-if 비교, 승인 이력 및 재현 가능한 코드·리포트를 제공해 사용자가 근거를 확인하고 직접 결정하도록 돕습니다.

## 작품명

**DataClinic — Explainable Human-in-the-Loop Data Preparation**

## 문제와 해결 방법

결측치나 이상값 후보를 어떻게 처리할지 정하는 기준이 불분명하면 정상 기록을 잘못 제거하거나, 대체 과정에서 분포와 통계가 달라질 수 있습니다. DataClinic은 원본을 유지한 채 문제 후보와 판단 근거를 보여주고, 처리 전후 영향을 미리 비교한 다음 사용자가 직접 승인하도록 구성했습니다.

## 주요 기능과 활용 기술

현재 저장소의 실행 가능한 프로토타입은 [src/DataClinic.html](src/DataClinic.html)입니다.

| 기능 | 설명 |
| --- | --- |
| CSV 품질 진단 | 정확성, 완전성, 일관성, 유일성, 유효성, 적시성 관점에서 검토 후보를 찾습니다. |
| 원본 근거 확인 | 문제 값과 원본 행을 연결해 보여줍니다. 여러 CSV를 올리면 ID 등 공통 열을 기준으로 참조 테이블을 함께 확인할 수 있습니다. |
| 처리 방법 비교 | 유지, 표시, 삭제, 대체 등 선택 가능한 방법을 미리 적용해 행 수와 통계 변화, 분포를 비교합니다. |
| 사용자 승인과 이력 | 사용자가 처리 규칙을 승인하면 버전 이력에 남고, 이전 승인 취소와 버전 복원을 할 수 있습니다. |
| 결과 저장 | 처리 결과 CSV, 승인 기록 JSON, 같은 규칙을 재실행하는 Node.js 코드를 내려받을 수 있습니다. |
| 선택형 AI 안내 | 지원 브라우저의 기기 내 AI 또는 OpenAI 호환 Chat Completions API로 진단 요약을 설명할 수 있습니다. |

**기술:** 단일 HTML 파일의 HTML·CSS·JavaScript, 브라우저 CSV 처리, 선택형 OpenAI 호환 Chat Completions API. 별도 패키지 설치 없이 실행할 수 있습니다. 입력 제한은 최대 6개 CSV, 합계 100MB, 파일당 20만 행·150열, 전체 30만 행입니다.

## 실행 방법

저장소를 받은 뒤 src 폴더에서 간단한 로컬 웹 서버를 실행합니다.

~~~~powershell
git clone https://github.com/kjjjk1/2026_DJU_OSS_AI.git
cd 2026_DJU_OSS_AI\src
py -m http.server 8000
~~~~

브라우저에서 [http://localhost:8000/DataClinic.html](http://localhost:8000/DataClinic.html)을 열고 샘플 또는 CSV 파일로 시작하세요. Python이 없다면 다른 정적 파일 서버를 사용해도 됩니다.

### AI API 설정

앱 오른쪽 위의 **고급 기능 → AI API 설정**에서 OpenAI 호환 Chat Completions 주소, 모델 이름, API 키를 입력할 수 있습니다. API를 설정하지 않아도 진단과 데이터 기반 추천 기능은 사용할 수 있습니다.

> **API 키 보안:** 현재 프로토타입은 브라우저에서 API를 직접 호출합니다. 키는 페이지 메모리에만 보관되지만 브라우저 개발자 도구에서 노출될 수 있으므로 공개 시연이나 배포에 실제 키를 넣지 마세요. 공개 서비스는 키를 서버에 보관하는 프록시를 사용해야 합니다. API 요청에는 원본 행 대신 열 이름, 진단 후보와 집계 통계를 전달합니다.

## 출처와 라이선스

- 시연용 천식·거래 자료는 앱에 포함된 합성 예시입니다.
- 선택형 AI 기능은 사용자가 지정한 OpenAI 호환 API를 호출합니다. API 키와 제공자 이용 조건은 해당 제공자의 정책을 따릅니다.
- 프로젝트 라이선스는 아직 정하지 않았습니다. 별도 라이선스를 추가하기 전에는 저장소 코드를 재사용할 때 권한을 확인해 주세요.

## 현재 구현 범위

- CSV 기반 브라우저 프로토타입이 저장소에 포함되어 있습니다.
- 이 버전은 XLSX 파일 입력, 서버 측 API 프록시, 여러 사용자가 공유하는 온라인 협업 기능을 제공하지 않습니다.
- 자동 진단은 검토 후보를 제시합니다. 후보가 실제 오류인지와 처리 적절성은 사용자가 원자료와 분석 목적을 바탕으로 판단해야 합니다.
